# Raman's Website

A simple, responsive personal website built with plain HTML, CSS and JavaScript. No build step needed.

## Features
- Hero, About, Projects and Contact sections
- Light/dark mode toggle (remembers your choice)
- Mobile-friendly menu and layout
- Fade-in animations on scroll

## View it locally
Open `index.html` in any browser.

## Customize
- **Text:** edit `index.html` (your name, bio, projects).
- **Colors:** change the variables at the top of `styles.css` (for example `--primary`).
- **Contact form:** it's a demo right now. To receive real messages, connect a service such as [Formspree](https://formspree.io).

## Publish for free with GitHub Pages
1. On GitHub, go to **Settings → Pages**.
2. Under **Source**, choose the branch and the `/ (root)` folder.
3. Save. Your site will appear at `https://<username>.github.io/<repo>/`.
